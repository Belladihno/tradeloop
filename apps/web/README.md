# Tradeloop Web

Buyer/seller marketplace (Next.js 14 App Router) backed by `@tradeloop/api`.

## Commands

| Command | Description |
|---------|-------------|
| `pnpm --filter @tradeloop/web dev` | Dev server on :3001 |
| `pnpm --filter @tradeloop/web build` | Production build |
| `pnpm --filter @tradeloop/web lint` | Typecheck |
